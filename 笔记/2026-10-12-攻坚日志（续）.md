## 一、茶杯狐（cupfoxyy.com）翻页修复

### 现象
- 茶杯狐源能播放（解析极快，一打开就出片），但"不能翻页"——鼠标滚 4 下就没内容了（每页只有 24 个左右）。

### 根因
- 网站首页大分类（电影/电视剧/综艺/动漫）下只有"推荐"内容，列表不足一页，翻页无数据。
- 真正能翻页的是**站内子分类**：
  - 电视剧 → 国产剧 / 香港剧 / 欧美剧 / 韩国剧 / 台湾剧 / 日本剧 / 泰国剧
  - 电影 → 动作片 / 喜剧 / 爱情……
- 用**子分类**作为 jar 的分类 tab，每个子分类都有完整分页 → 就能翻页了。

### 解法（关键知识点，通用）
- jar 的 `homeContent` 里，分类 tab 直接用网站的子分类链接（如 `/vodtype/xxx` 对应路径），不要用首页大分类。
- 之前 gqc（共青春）、飞快也是用这个方法做分类 → 都能翻页。
- **凡"分类能显示但翻不了页"的站，优先试站内子分类。**

### 验证
- 模拟器 OK影视 实测通过：分类（国产剧等）可翻页、可播放、可搜索。

## 二、TVBox源地址大全 导航改造（b.json + 新前缀 + 密码锁）

### 需求（用户原话整理）
1. 把 b.json（57 源接口）加进导航；
2. 新部署域名 `zhouyu86-bh1.pages.dev` 做前缀，**所有源**都加一份该前缀地址；
3. 导航页加密码锁，密码 **123456**。

### 实现要点
- 页面结构：`sources` 数组（10 个普通源，JS 自动渲染）+ 2 张**静态卡片**（tvbox18、b.json）。
- **b.json 不能进 sources 数组**：渲染逻辑硬编码 `${域名}/${src.en}/api.json`，而 b.json 路径是 `/b.json` → 必须写成独立静态卡片（和 tvbox18 一个套路）。
- 静态卡片的**删除/恢复/渲染要特判**：`deleteUrl` / `restoreAllUrls` / `renderAll` 里对 `en === 'tvbox18' || en === 'b'` 单独处理（删一行→隐藏该行；全部删→隐藏整卡；恢复→全部还原）。
- 密码锁：页面 `<script>` 开头先验证 `localStorage('nav_unlocked')`，密码 123456；输错直接替换 body 并 `throw`，页面不渲染。

## 三、免费主机 / 免费域名调研知识点（今天踩点）

### 免费主机
- **Serv00**：免费 SSH 主机，但 **3 个月不上线会被删号** → 要定期访问保活。
- **domcloud.co**：免费，空间小（约 1.5G），长时间不访问可能休眠（要重新唤醒）。
- **Koyeb**：免费部署（GitHub 登录授权），约 2G 空间，比 domcloud 大；国外节点，访问速度一般（类似 GitHub 的慢）。
- **三丰云**：国内免费主机（1核1G 免费机），可以把自己电脑上的自动更新接口迁上去长期跑；但免费机可能被回收/重启，接口要能自愈。
- **150cn（亿速云）**：有 1 元/月的低配学生机/特价机。
- **Oracle Cloud 免费层**：注册**必须信用卡验证**（扣 1 美元测试后退回）；国内**储蓄卡/借记卡不行**，要信用卡或外币卡。

### 免费域名
- **eu.org**：免费域名（如 `xxx.eu.org`），注册要审核（发邮件验证）；审核通过后**长期稳定**，比平台送的子域名稳得多。
- **Cloudns**：免费 DNS 托管 + 域名管理，可给 eu.org 做 NS / 解析记录。
- 免费域名申请时绑定了身份信息，**审核不过不会解绑身份**（身份记录保留在平台）。

### 经验总结
- 免费主机/免费域名都可能"睡着 / 被回收"：要么定时访问保活，要么接受风险。
- **部署接口最省心的方案**：Cloudflare Pages + GitHub 自动构建（免费、不用保活、自动更新）。

## 五、今天的新认知（一句话收藏）

- 站点能开但 jar 抓不到 → 先查**证书信任链**（自签名/中间证书）：信任全部证书 + SSLContext TLS + hostnameVerifier 恒真 + 自定义 Dns 兜底多个 A 记录。
- 手动加了 `Accept-Encoding: gzip` 而 okhttp 不自动解压 → 主页乱码 → **删掉 gzip 头**。
- `homeContent` 返回格式不对 → 分类 tab 只剩"推荐" → 用 `Result.string(list, items)`，别用 `Result.get().vod(items).string()`。
- 搜索页 DOM 结构和首页不同 → 要**单独写 parseSearchList**（嵌套 div 计数切块解析）。
- **"能播放不能翻页"的站 → 分类改成站内子分类**（国产剧/动作片等）。
- **b.json 这类"非 /api.json 路径"的接口 → 导航里做独立静态卡片**，别塞进自动渲染数组。
- 免费接口地址要逐个验证（curl 测 http_code），不能用"应该能开"代替实测。
