## 二、新知识点（可复用，重点）

### 1. cdndefend JS 挑战破解（本源码最大难点，已实证可移植 Java）
- 首次请求任意页面返回 **850**，正文是 JS 挑战页。
- 挑战页内嵌数组：`a0_0x2a54=['token',…]`，正则 `a0_0x2a54=\[([^;\]]*)\]` 取出 token（当前值 `26F4497D23979FF11C34B67261D2FEF78DC78DA4`）。
- 计算：`n1 = Integer.parseInt(token.substring(0,1), 16)`（=2）；暴力找 i（从 0 起），满足 `sha1(token + String.valueOf(i))` 的十六进制串第 n1 位 == 0xB0 且第 n1+1 位 == 0x0B。
- 当前 i = **52882**；cookie = `cdndefend_js_cookie=<token><i>`。
- Java 实现（WwwKeke.java 已内置）：`get()` 检测响应含 "cdndefend" 或状态 850 → 自动重算 cookie → 重试（最多 6 轮）。**以后遇到 850 + 挑战页的站直接套这套**。

### 2. 可可影视 URL 规则
- 分类首页 `/channel/{tid}.html`（1电影/2连续剧/3动漫/4综艺纪录/6短剧）**不可翻页**（48 条混合内容，无分页链接）。
- **真正可翻页列表**：`/show/{tid}------.html`（第1页18条）+ `/show/{tid}-----3-{page}.html`（第N页）；下一页链接 `class="page-item-next"`，无此链接即尾页。
- 列表条目：`<a href="/detail/{id}.html" class="v-item">`；图片 `data-original="/vod1/…"`；片名 `.v-item-title`（不带 style 的才是片名，带 display:none 的是站名水印）。
- 详情 `/detail/{id}.html`：标题 `.detail-title` 内**第2个** `<strong>`；简介 `.detail-desc p`；`.detail-info-row-side`("导演:"/"演员:"/"首映:"/…) + `.detail-info-row-main`。
- 线路/集数：`.source-item .source-item-label`（N 条线路）与 `.episode-list` 块**按同样顺序一一对应**（display:none 控制显示，第 N 个块=第 N 条线路）；集数 `/play/{id}-{sid}-{nid}.html`，`.episode-item` 的 span 是集名。
- 播放页 `/play/…`：真实地址在 JS `function gogogo(){ const playSource = { src:"…index.m3u8?appId=kkdy&sign=…&timestamp=…&ref=0"}`，正则 `src:\s*"([^"]+)"` 提取。
- 搜索：`/search?k={词}&t={签名}`，**t 每次刷新页面都变**，必须先 GET 最新首页从热搜链接抓（正则 `search\?k=[^"&]*&amp;t=([^"&]+)`），首页 t 对任意关键词通用。
- 采集 API `api.php/provide/vod/*` 一律 403，此站无采集接口，只能爬虫。

### 3. 大坑：线路只显示一条（本次修的 bug）
- 详情页集数块正则最初写 `<div class="episode-list"([\s\S]*?)</div>\s*</div>`，**尾部多要一个 `</div>`**，导致非贪婪回溯把所有线路块吞进第一个 → OK影视 只显示 1 条线路。
- 修正：`<div class="episode-list"([\s\S]*?)</div>`（块内只有 a 标签无嵌套 div，第一个 `</div>` 即块结束）。**教训：正则尾部不要凭空多要求闭合标签。**

### 4. 图片全站 403（无解，接受）
- 全站封面图请求返回 **403 Forbidden（openresty）**：主域带/不带 cookie 都 403/850，CDN 域 vf.wkcyvs.cn 404，镜像域 kkys14/kkys15 850。
- **连网站自己的网页都不显示图片（全是占位图）**—— 是站方图片服务挂了/被限制，不是我们 jar 的问题，OK影视 无图属正常。
