## 二、瓜子影视电脑版技术栈（Windows v1.0.5）

- **Flutter 桌面应用**：flutter_windows.dll（19MB）+ data/app.so（12.6MB，Dart AOT）+ flutter_assets
- **播放内核**：media_kit + libmpv-2.dll（mpv 播放器）
- **其它**：flutter_inappwebview（网页播放）、connectivity_plus、window_manager、screen_retriever、url_launcher、permission_handler、volume_controller
- 安装包是 **Inno Setup 定制版**（innoextract/7-Zip/WinRAR 全部解不开，loader 被改过）；静默安装后**主 exe 缺失**（疑似被腾讯电脑管家拦截删除），但 dll/app.so/资源全解出来了

## 三、API 架构（核心成果）

### 3.1 多域名轮换机制（关键！）

- 硬编码默认 API：`https://api.8kxv29.com`（**当前已挂**，所有路径返回 goto 跳转壳 HTML，不是真实 API）
- 旧域名：`http://api.arilks.cc/index/v1App2`（410 已死）
- **有效域名列表来自远端加密配置**：
  - 地址：`https://pool-sg.oss-ap-southeast-1.aliyuncs.com/kgq/kgqapi-android.json`
  - 结构：`{"data": "<base64 密文 272 字节>"}`
  - 机制：`updateRemoteBaseUrls` / `refreshBaseUrl` / `get:remoteBaseUrls` / `MultiDomainManager` / `_selectDomainByWeight`（按权重选域名）
  - → **解密这个配置 = 拿到当前有效域名**，目前 key 未破解

### 3.2 完整接口清单（ThinkPHP 风格 /控制器/方法）

基础路径 = `{域名}/Index/CategoryList` 这种格式（非 /index.php?m=...）：

**首页/分类**
- `/Index/CategoryList` 首页分类列表
- `/Index/indexPid` 首页 pid
- `/Category/GetChoiceList` 分类选项
- `/Category/GetModuleList` 分类模块

**发现/搜索**
- `/Discover/GetIndex` 发现首页
- `/Discover/GetList` 发现列表
- `/Discover/GetSubCateList` 子分类
- `/Search/GetCondition` 搜索条件
- `/Search/GetConditionList` 搜索条件列表
- `/Search/ShowHots2` 热搜

**资源/播放（做 jar 源最核心）**
- `/Resource/GetVodInfo` 视频详情（分类/剧集结构）
- `/Resource/vurlDetail`（大小写均有出现）播放地址详情
- `/Resource/GetOnePlayList` 单集播放列表
- `/Resource/ShortDramaChannel` 短剧频道
- `/Resource/BannerInfo` 横幅
- `/Resource/UserVod` 用户视频
- `/Resource/VodComment` 评论

**配置/用户/其它**
- `/Config/GetList`、`/Config/getUserConfig`、`/Config/setUserConfig`、`/Config/getCopyright`、`/Config/getPcPermanentUrl`、`/Config/getPcSportAppGuideUrl`
- `/AppUser/showOne2`、`/AppUserReport/add`、`/AppUserReport/vodType`
- `/UserHistory/index`、`/UserHistory/add2`、`/UserHistory/delete`
- `/UserCollect/newIndex`、`/UserCollect/add2`、`/UserCollect/delete`
- `/FeedInfo/addInfo`、`/FeedInfo/feedTag`、`/FeedInfo/upload2`、`/FeedInfo/feedHistory`
- `/VersionInfo/newIndex`
- `/Resource/AppUser`

> 做 TVBox jar 源只需：`CategoryList`（分类）+ `GetVodInfo`/`GetList`（列表/详情）+ `vurlDetail`/`GetOnePlayList`（播放地址）+ `Search/GetConditionList`（搜索）。

### 3.3 请求加密（待解）

- Dart 库：`package:encrypt`、`pointycastle`；自定义 `sport_aes_interceptor.dart`、`sport_aes_helper.dart`
- 解密函数：`decryptFromBase64` / `decryptBytes`
- 疑似 key/iv 常量（app.so 字符串池）：`ffffffffffffffffffffffffffffffff6c611070995ad10045841b09b761b893`（64hex，AES-128-CBC 的 key+iv 组合）、`97ff04a728735e6b6b098bdf983faaba`（×2）、`EEBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB`
- 用以上 key 组合 CBC/ECB 试解 kgq 配置 → **全部失败**（可能 key 需要转换，或加密流程自定义，或另有 key 藏在代码逻辑里）
- kgq 配置密文 272 字节（非 hex、非 zlib/gzip，就是 AES 密文）

## 六、踩坑记录（以后别再走）

1. **Inno 定制安装包**：innoextract（loader checksum mismatch）、7-Zip 完整版 7za（exit 2）、WinRAR 全解不开 → 静默安装是唯一能拿文件的路，但主 exe 可能被杀软拦截
2. **Flutter Windows AOT**：app.so 是 Dart AOT，字符串可提取但代码逻辑需反编译（Blutter 不支持 Windows）；Android 版才有成熟反编译工具链
3. **域名跳转壳**：api.8kxv29.com 返回的 goto HTML 是流量跳转，不是 API；判断接口是否真实 = 看返回是不是 JSON
4. **AES key 猜测**：app.so 里的 hex 串不一定是配置 key（可能是体育接口 sport_aes 专用），穷举 CBC/ECB + 多 key/iv 组合失败 → 别浪费时间瞎猜，直接抓包或反编译拿代码级 key
