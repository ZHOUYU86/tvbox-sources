## 一、核心突破（本轮）

### 1.1 抓到真实 API 域名（随机轮换）

通过抓包（mitmproxy + 雷电模拟器代理）捕获到**瓜子影视马甲版（暖心剧场）**的真实流量：

| 域名 | 状态 | 说明 |
|---|---|---|
| **`sdapi.e2wu4ht.com`** | ✅ **真实 API（活着）** | 随机 8 位短域名，当前有效 |
| api.w32z7vtd.com / api.umygrx3.com / api.rmedphk.com | ❌ 已挂（goto 跳转壳） | 历史随机域名 |
| api.8kxv29.com（Windows 版硬编码） | ❌ 已挂 | 被挂流量跳转 |
| api.arilks.cc（旧） | ❌ 410 | 彻底废弃 |
| vd.wmvbo.com | ✅ 视频流域名 | m3u8 分片源（120.232.104.141） |

**多域名轮换机制确认**：APP 内置动态域名列表（来自加密配置 kgqapi），随机 8 位域名 + 服务器下发生效域名，失效域名全部被挂 goto 跳转壳。

### 1.2 完整接口路径（POST，JSON）

从抓包拿到真实请求路径（`https://sdapi.e2wu4ht.com` + 以下路径）：

- `POST /App/Authentication/Device/signUp` / `signIn` — **设备认证（拿 token）**
- `POST /App/IndexList/indexList` — 首页/分类列表（返回 19.4KB）
- `POST /App/IndexPlay/playInfo` — 播放信息
- `POST /App/Resource/Vurl/show` — 播放地址（26KB）
- `POST /App/Resource/VurlDetail/showOne` — **播放详情**（与 Windows 版 app.so 里的 `/Resource/VurlDetail` 完全同源 ✅）
- `POST /App/UserInfo/getUserInfo` — 用户信息
- `GET vd.wmvbo.com/{hash}/{...}` — 视频流（m3u8）

### 1.3 响应加密体系（已确认，待破解）

直接请求 `sdapi.e2wu4ht.com` 验证：
```json
POST /App/IndexList/indexList  →  {"code":200,"msg":"请求成功","data":{"response_key":"203971ECEB952F6CF687DE67286D9182","keys":"<base64密文128B>"}}
POST /App/IndexPlay/playInfo   →  code 300 "资源ID错误"（接口活着，需参数）
POST /App/Resource/Vurl/show   →  code 301 "token 不能为空"（需要设备认证 token）
```

- **response_key**：每次请求返回的 32 位 hex（服务器生成）
- **keys**：base64 AES 密文（明文是 JSON 数据）
- **token**：设备认证后获取，请求数据接口必须带

### 1.4 解密尝试（未成功，下一步动态拿 key）

- 尝试 key = response_key hex / MD5(response_key) / SHA256 派生 + iv = response_key前16/全0/全f，AES-128/256 CBC/ECB → **全部失败**
- key 由 APP 内部算法生成（固定盐 + response_key 或其它变换），需动态获取
- 下一步：**模拟器开 root → Frida hook APP 解密函数** 或 **装 mitm 证书抓全明文请求**

## 三、抓包环境搭建方法（踩坑记录）

1. **模拟器代理**：`adb shell settings put global http_proxy 宿主机IP:8888`（雷电访问宿主机用局域网 IP，不是 10.0.2.2）
2. **mitmdump**：`mitmdump.exe -p 8888 --ssl-insecure`，输出重定向到日志文件
3. **无需装证书也能看到**：HTTPS 请求的域名 + 路径（CONNECT 记录 + 请求行），响应内容需证书解密
4. 模拟器未 root（雷电默认关），装系统证书需先开 root

## 四、下一步计划

1. **雷电模拟器开 root**（用户配合：设置→其他→ROOT）→ `adb root` + remount → 装 mitm 系统证书 → 抓**完整明文请求**（token 获取流程、参数结构、响应明文）

## 五、已确认结论

- **瓜子影视数据接口 = sdapi.e2wu4ht.com 系**（动态域名，随时可能换，但路径结构稳定）
- **响应必加密**（AES），**请求必带 token**（设备认证）
- 做 jar 源的核心 = 复现「设备认证拿 token + 请求 + 响应解密」三步
- 王二小 wex 源 = 同数据源（同款加密），他破解过，我们自研做出来后就不依赖他
