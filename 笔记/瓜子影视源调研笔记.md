# 瓜子影视源调研笔记（王二小 wex 接口分析）

> 日期：2026-10-13 | 目的：研究王二小接口里"瓜子影视"源的做法，为王二小源失效后自研备用

## 一、王二小接口位置（本地 D 盘）

- 目录：`D:\tvbox\wex\`
- 结构：
  - `api.json`（34KB）—— 王二小接口的源配置
  - `spider.jar`（1MB）—— jar 爬虫合集（Guard 加固）
  - `txt/` —— 文本类源（bilibili、少儿/初高中/戏曲等分类）

## 三、spider.jar 技术分析（为什么挖不出数据源）

- jar 内容：
  - `classes.dex`（仅 39KB）—— 壳，只含各 Guard 类的类名，无任何 URL/域名
  - `assets/wexguard_v7.so`、`wexguard_v8.so` —— native 加固库（48KB）
  - `assets/wexshinidie.guard` —— guard 资源
- .so 编译信息：**Obfuscator-LLVM（heroims）混淆**，字符串加密，扫不出 API 域名
- 结论：**王二小把瓜子影视的真实数据接口（域名+接口结构）加密藏进了 native 层，反编译 jar 学不到内部实现** —— 这是他的保护手法

## 四、以后自研瓜子影视源的可行路线

### 路线 A（推荐）：抓包瓜子影视 APP
1. 幺爸有瓜子影视电脑版/安卓版（可装在雷电模拟器）
2. 模拟器开抓包（HttpCanary 或电脑 Fiddler/Charles 代理）
3. 在 APP 里浏览分类→详情→播放，抓出：
   - 数据接口域名（列表/详情/搜索/播放）
   - 分类 id 结构、翻页参数、搜索格式
   - 播放直链（m3u8/mp4）的解密规则（瓜子影视画质 2592×1080 = 高清直链源）
4. 按咱们的 CatVodSpider 模板写 Java 类（参考 WwwDmxq/WwwQqys），编译进 all_feikuai_new.jar

### 路线 B：找瓜子影视 Web 端
- 官网 gz99.app 目前是下载引导页（马甲包）
- 若瓜子影视有网页播放版，可像千千影视一样做网页爬虫源

### 路线 C：等王二小源继续用（现状）
- 王二小的"瓜子┃秒播"源现在正常，先继续用
- 笔记存档，等它失效再启用路线 A

## 五、关键经验

1. **别指望从别人加固的 jar 里"学做法"** —— Obfuscator-LLVM 混淆 + native 壳会把数据源藏死
2. **做 APP 类影视源的正路 = 抓包**：APP 在跑时抓它的 API 请求，一次抓全（首页/分类/详情/搜索/播放）
3. 高清直链源（秒播/4K 系列）画质由片源 CDN 决定，2592×1080 这类是 APP 直接给的高清 m3u8，比网页聚合站（1280x536）体验好
4. 抓包优先级：先抓**播放接口**（最关键，解密规则），再补列表/详情/搜索
