====================================================
好看影视（hkys2.cc）TVBox 接口设计方案
====================================================
说明：本文档基于 Python 实测抓取验证写出的框架，数据全部真实可复现。

----------------------------------------------------
一、网站结构（实测结论）
----------------------------------------------------
1. 分类（首页导航，站内叫法）
   /v/dianying/   电影（首页 164 部）
   /v/dianshiju/  电视剧（首页 128 部）
   /v/zongyi/     综艺（首页 64 部）
   /v/dongman/    动漫（首页 64 部）
   站内还有更多细分类：动作片、喜剧片、剧情片、动画片、
   爱情片、恐怖片、科幻片、奇幻片等（/v/<拼音>/）。

2. 影片列表卡片
   每个影片 = <a href="/show-<ID>/" title="片名">
   例：/show-278582/ = 《重生》

3. 详情页
   /show-<ID>/
   内容：片名(H1)、海报图(data-src)、年份、简介、
   线路（5 条：FF节点/HD节点/BF节点/KK节点/HN节点）、
   集数面板（每集 = /paly-<ID>-<线路>-<集数>/）

4. 播放页
   /paly-<ID>-<线路sid>-<集数nid>/
   内含 JS 变量：player_aaaa = { ... }
   url 字段是百分号编码的 m3u8 直链，解码后形如：
   https://c1.rrcdnbf1.com/video/xxx/index.m3u8&dyvip&dianying&next=
   取 & 前面的部分 = 真正的 m3u8（实测 200 可播）

5. 翻页（重要修正）
   分类首页 /v/<分类>/ 只有一页（站方不翻页）。
   真实翻页在“影片库”：
   /pianku-dianying--------<页码>---/  最新电影 第N页
   /pianku-dianshiju--------<页码>---/ 最新电视剧 第N页
   /pianku-zongyi--------<页码>---/    最新综艺 第N页
   /pianku-dongman--------<页码>---/   最新动漫 第N页
   每页 72 部。例：2024 电影库共 58 页。
   还支持年份筛选：/pianku-dianying--------1---2024/

6. 搜索
   /search------<关键词>/ 实测 403 Forbidden，
   站方关闭了接口搜索。三种形态+suggest 全不可用。
   → 取舍：接口搜索返回空结果（可后续把“搜索”映射到
     影片库翻页，先按空返回处理，不误导用户）。

----------------------------------------------------
二、爬虫 jar 四大块（WwwHkys 实现框架）
----------------------------------------------------
1. 首页分类 homeContent
   - 固定 4 个分类：电影/电视剧/综艺/动漫
   - 请求 SITE + /v/dianying/ 取第一分类内容
   - 正则：<a href="/show-(\d+)/" title="(片名)"
     提取 ID + 片名，图片用 data-src 锚点
   - headers：Chrome 浏览器 UA + Referer = 站点首页
     （站点对 okhttp UA 返回 403，浏览器 UA 返回 200）

2. 分类列表翻页 categoryContent
   - 首页（第1页）：/v/<分类>/
   - 第2页起：/pianku-<分类>--------<页码>---/
   - 同样正则提影片列表

3. 详情页 detailContent
   - 请求 /show-<ID>/
   - 片名：<h1 class="page-title">
   - 图片：<img data-src="...">
   - 年份：itemprop="datePublished"
   - 简介：video-info-content
   - 线路：data-dropdown-value="XX节点"
   - 集数：module-blocklist 面板内
     <a href="/paly-<ID>-<sid>-<nid>/"><span>第N集</span>

4. 播放页 playerContent
   - 请求 /paly-<ID>-<sid>-<nid>/
   - 定位 player_aaaa= 到 JSON 对象（大括号配对截取）
   - 解析 encrypt=1 → url 百分号解码
   - 解码后取 & 前 = m3u8 直链，交给播放器

5. 搜索 searchContent
   - 站点无搜索接口（403）→ 返回空（Result.error 或空列表）

6. 网络层
   - OkHttpClient 全信任证书 + 浏览器 UA + Referer
   - 5 次重试

----------------------------------------------------
三、JSON 接口配置（b_test_hkys.json）
----------------------------------------------------
- spider 全局：jar 地址;md5;校验值
- sites 里 hkys2 条目：
  key=hkys2, name=好看影视, type=3（jar 爬虫）
  分类参数 dianying/dianshiju/zongyi/dongman
- 其余 56 个源保持不变（原 b.json 基础上加入）
